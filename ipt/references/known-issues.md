Older-IPT material is kept because the same environment condition (permissions, proxy, heap, JDBC driver, Registry state) still produces the same symptom. Conventions: first issue in each Issues cell is a full link; `#n` = https://github.com/gbif/ipt/issues/n (`gh issue view n --repo gbif/ipt`). **⚠open** after an issue link = still OPEN in `references/issues-index.tsv`; `[INFERENCE]` = the miner's reading, not a maintainer statement; `[current]` = checked against the current source/manual; `rNNNN` = SVN revision of IPT ≤ 2.0.x; "fixed 3.x backlog" = NOT fixed. "Versions" = affected → fixed (GitHub milestone, or maintainer comment; "n/a" = closed without milestone). Rows inside a theme are ordered most-current issue first. ## How to use

1. **Grep this file by the exact error / log message** (backticked strings are verbatim grep keys; also try the template name or exception class). Start with the cheat sheet, then the theme tables.
2. Not covered → search `references/issues-index.tsv` by keyword (columns: number, state, created, closed, labels, title), e.g. `grep -i "keyword" references/issues-index.tsv`.
3. Detail → `gh issue view <n> --repo gbif/ipt --comments`.
4. Check Java/Tomcat and IPT version first (Release timeline below); read `logs/admin.log` (WARN+), `logs/debug.log` (enable Debug mode in Admin), Tomcat `catalina.out`.

### Fast triage rules (3.x era)

1. Odd after an upgrade → look for `Cannot read resource configuration for <shortname>` in the logs (resource silently dropped) and check Java/Tomcat versions (theme 12, 1).
2. Publication failed with `Invalid EML file: org.xml.sax.SAXParseException; lineNumber…` → an EML field is empty / has a control char / `&nbsp;`; inspect that line of the EML downloaded from Overview (theme 5).
3. `Java heap space` / `OutOfMemoryError` → raise `-Xmx` via `CATALINA_OPTS` in `setenv.sh` (theme 8).
4. `413`, `502 Proxy Error`, upload "succeeds" but file missing → reverse-proxy/WAF limits (nginx `client_max_body_size`, Apache timeout, Cloudflare), not IPT (theme 2).
5. `An error of type REGISTRY` / `HTTP 401/400` on publish → tokens (`config/registration2.xml`), dataset deleted at GBIF, organisation just changed (theme 3).
6. "0 records" or preview shows only columns → SQL returns 0 rows, row shift from CR/LF or wrong `Field quotes`; imported-but-never-published resources show 0 in the Manage list (themes 4, 7).

## 2. Base URL, proxy, reverse proxy, HTTPS, uploads/WAF, CSRF, session

Check the browser console (F12) for `413`/`502` on `POST /manage/addsource.do`: the IPT log is usually EMPTY for proxy/WAF rejections because the request never reaches Tomcat. The *proxy URL* in IPT settings is for an **outbound** institutional proxy, not for your reverse proxy.
